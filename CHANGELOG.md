# Changelog

## 0.1.0

- Gear Sets window on the inventory: save, update, rename, icon, delete, equip.
- Partial sets (ignore any slot or hotbar position) and hotbar layout restore.
- Sets follow the exact item copy, with a named substitute when it is missing.
- Radial picker in Valheim's own radial: H opens it on your sets, and G's radial (and the gamepad radial) has a Gear Sets group. The classic ring is still available in the config.
- Tooltip line and inventory cell marker for set items.
- Confirmation before dropping or obliterating set items.
- Integrations: ExtraSlots, Quick Stack Store Sort Trash Restock, MyLittleUI; works alongside AutoShield.
